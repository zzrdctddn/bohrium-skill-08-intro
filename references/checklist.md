# 引言写作自检清单（逐项打钩）

## 结构完整性
- [ ] 四段齐全：背景 / 相关工作 / 空白 / 贡献
- [ ] 段间承接关系明确（前段结论引出后段）
- [ ] 贡献为 3–5 条可核对条目

## 论断与来源
- [ ] 每个实质论断都有 claim_id
- [ ] 论断类型已标注（in_paper_fact / prior_result / author_judgement）
- [ ] prior_result 均有可定位来源与 location
- [ ] 查不到的来源标 unverified 并进 human_review_items

## 相关工作
- [ ] 按维度分组，非时间罗列
- [ ] 每格含"取舍"与来源
- [ ] 元数据（作者/年份）齐全，缺项已标注

## 研究空白
- [ ] 由共同限制 / 未覆盖场景 / 冲突结论推出
- [ ] 有来源，非"研究尚少"空话
- [ ] 显式说明本文如何填补

## 贡献
- [ ] 每条贡献对应正文图表/实验/公式编号
- [ ] 无夸大，适用范围有限定

## 引用
- [ ] 正文引用与文末条目一一对应
- [ ] 无孤儿引用、无未引用条目（除非允许）
- [ ] 引用格式统一，元数据准确

## 边界
- [ ] 无材料外新增事实/数值/单位
- [ ] status 诚实（success/partial/blocked）
- [ ] partial/blocked 均写明原因与缺口
- [ ] 独立核对完成，改动均在 change_log
